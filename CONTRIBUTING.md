# Contributing

Octom is intentionally simple. Before you open a pull request, please open an
issue to discuss the change. Features that turn it into a full CRM suite are
out of scope.

1. Fork the repository and create a branch.
2. Run `npm ci`, then `npm run build && npm test`.
3. Keep changes small and include tests where it makes sense.
4. Keep texts in both languages (EN and RO) in the dictionary files.
