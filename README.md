# Octom

Know who to contact today.

Octom is a deliberately simple CRM built around follow-ups. It shows who to
contact today, keeps the history in one place and helps you draft the message.
It is made for freelancers, consultants, small agencies and small B2B teams.

## Features

- Contacts with notes, status and pipeline view
- Follow-ups with due dates and a daily list
- AI-drafted messages
- Team workspaces with invitations and assignees
- CSV import and export
- English and Romanian interface
- Optional daily summary email

## Stack

Next.js, React, TypeScript, Tailwind, Supabase (Postgres, Auth, row level
security), Vitest and Playwright.

## Run it locally

1. `npm ci`
2. Copy `.env.example` to `.env.local` and fill in your own values.
3. `npm run dev`

Database setup notes will be added to a `docs` folder.
